# Apollo 2.0.6 (106)

Hotfix for 2.0.5: after leaving the Quadro and returning, horizontal scrolling rubber-banded back and the right-hand columns could not be reached until the window was resized. The board page outlives each mount, but every mount builds a new native scroll container whose document width started at zero, and the page only posted its geometry when it changed. The host now keeps the last reported width for new containers, and every full snapshot makes the page report its geometry again.

`swift test -Xswiftc -DAPOLLO_TASKS_REACT -Xswiftc -DAPOLLO_AGENDA_REACT -Xswiftc -DAPOLLO_BOARD_REACT --no-parallel` passed 263 XCTest tests (4 skipped) and 33 Swift Testing tests. In the Vite fixture, a full snapshot re-posts the layout width (2552 px for 9 columns in a 1280 px viewport) while an ordinary patch posts nothing. The leave-and-return path was not driven in the app by automation (no accessibility permission); the 2.0.6 build was opened on Marconi's Mac before the release was approved, and whether that path was exercised there is not recorded.
